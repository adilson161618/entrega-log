Política de Privacidade

Versão 1.0 — última atualização: 13 de maio de 2026

Esta Política de Privacidade explica como o aplicativo EntregaLog coleta, usa, armazena e protege as informações dos seus usuários, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

Resumo rápido: Coletamos apenas o necessário para o app funcionar — seu nome, WhatsApp, localização durante o uso e endereços que você registra. Não vendemos nem compartilhamos seus dados com terceiros. Você pode excluir sua conta a qualquer momento direto pelo app.

1. Quem somos

O EntregaLog é um aplicativo independente desenvolvido para ajudar entregadores autônomos a organizar suas rotas e compartilhar conhecimento sobre endereços difíceis.

Para qualquer dúvida sobre privacidade ou para exercer seus direitos como titular de dados, fale conosco:

  • E-mail / WhatsApp: entre em contato pela opção "Falar com suporte" dentro do app

3. Como usamos seus dados

  • Para fazer o app funcionar (mostrar mapa, organizar entregas, gerar rota).
  • Para manter o banco colaborativo de endereços, onde a comunidade de entregadores ajuda uns aos outros.
  • Para gerar relatórios pessoais (apenas você vê).
  • Para responder seu suporte quando você nos contata.
  • Para enviar avisos importantes sobre o app (quando aplicável).

Nunca usamos seus dados para anúncios direcionados, nem vendemos sua informação para terceiros.

4. Compartilhamento com terceiros

Usamos os seguintes serviços para o app funcionar:

  • Supabase — armazena o banco de dados de usuários, endereços colaborativos e histórico.
  • OpenStreetMap / Nominatim — provê o mapa e converte endereços em coordenadas.
  • ViaCEP — busca endereços a partir do CEP.
  • Serviço de OCR (IA) — quando você fotografa uma etiqueta, a imagem é enviada para um modelo de IA para extrair o texto. A foto não é armazenada após o processamento.

Esses serviços recebem apenas o estritamente necessário para a função solicitada.

5. Endereços colaborativos — atenção

Quando você toca em "Salvar para todos os entregadores" na aba Registrar (ou registra um ponto no mapa), o endereço, dica e foto que você adicionou ficam visíveis publicamente a outros usuários do app, junto com o seu nome de exibição.

Use essa função apenas para informações que você concorda em compartilhar. Não inclua dados pessoais do destinatário (CPF, nome completo, telefone, número do apartamento individual).

6. Onde os dados ficam guardados

  • No seu celular: entregas do dia, configurações, foto da localização (até você sincronizar).
  • Em servidores Supabase: dados de conta, banco colaborativo de endereços, histórico sincronizado. Os servidores ficam em região configurada pelo provedor.

Aplicamos Row Level Security (RLS) no banco para garantir que cada usuário só acesse o que tem permissão.

7. Por quanto tempo guardamos

  • Dados de conta: enquanto a conta existir.
  • Endereços colaborativos: mantidos enquanto úteis à comunidade, mesmo após o registrador excluir a conta (mas o nome dele é anonimizado).
  • Histórico individual: 7 dias na versão gratuita, ilimitado na versão Premium.
  • Logs de erro: até 90 dias.

8. Seus direitos (LGPD)

Como titular dos dados, você tem direito a:

  • Acessar os dados que temos sobre você.
  • Corrigir dados incorretos.
  • Excluir sua conta e os dados pessoais associados — basta usar o botão "Excluir minha conta e meus dados" em ⚙️ Configurações.
  • Exportar seus dados em formato legível (entre em contato pelo suporte).
  • Revogar qualquer consentimento dado.
  • Reclamar à Autoridade Nacional de Proteção de Dados (ANPD) se entender que algo não está sendo cumprido.

9. Segurança

Usamos HTTPS em todas as comunicações, controle de acesso por linha no banco (RLS) e armazenamento seguro de credenciais. Mesmo assim, nenhum sistema é 100% imune — em caso de incidente, você será notificado no app e nos canais oficiais.

10. Crianças e adolescentes

O EntregaLog é destinado a maiores de 18 anos que exercem atividade profissional de entrega. Não coletamos intencionalmente dados de crianças.

11. Permissões do celular

  • Localização (GPS): mostrar você no mapa e calcular rota.
  • Câmera: tirar foto da etiqueta (OCR) ou da localização do endereço difícil.
  • Microfone: comando de voz, apenas quando você toca no botão 🎤.
  • Armazenamento: salvar suas entregas e fotos no aparelho.
  • Internet: sincronizar com o servidor.

Todas as permissões podem ser revogadas a qualquer momento pelas configurações do Android.

12. Mudanças nesta política

Se alterarmos esta política, vamos atualizar a data acima e, em mudanças relevantes, avisar dentro do app antes da nova versão entrar em vigor.
